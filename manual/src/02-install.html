Installing and updating

PT/FM is installed from a web page, install.html, that comes with the firmware. It works offline: the firmware and the demo disk are inside the page. Get the latest from PT/FM's home, hitosu.github.io/ptfm, or from its repository, github.com/hitosu/ptfm (the dist folder).

Before you start

  • Open install.html in Chrome or Edge, on a computer or an Android phone. Safari and iPhones cannot talk MIDI from a web page.
  • Connect the FM-1 by USB and switch it on. Keep it connected until the page says it is done.
  • When the browser asks, allow MIDI devices, SysEx included: the whole install goes through MIDI.
Changes not yet saved on the FM-1 are lost by an install, as when it is switched off. Press SAVE on the FM-1 first.

INSTALL FIRMWARE

Writes PT/FM over whatever firmware the FM-1 runs.

  1. Open install.html and connect the FM-1.
  2. Press INSTALL FIRMWARE. The page shows its progress, the kilobytes written of the firmware's; the FM-1 restarts by itself.
  3. When the page says it is done, the FM-1 starts PT/FM on its STATUS screen. Keep it connected until the page says Done: after an install over an older PT/FM there may be samplers to convert first (below).

Over PT/FM (an update), your songs, patterns, instruments, samples and settings stay where they are in PT/FM's own memory, the user area; the install itself writes nothing there. Over another firmware, keep a copy of your work first: other firmwares erase that memory when they are installed. The EDITOR page saves the FM-1's whole library to a file (chapter 17).

Converting an older PT/FM's samplers. Before this version, a sampler cartridge held its samples inside it; now samples are things of their own (chapter 8). When the FM-1 held samplers of the older kind, the page converts them itself right after the install, by talking to PT/FM, and says how far it is: Converting the samplers to the new form: 2 of 5. Keep the FM-1 connected. It converts whole samplers one save at a time, in number order, into free room only, and touches nothing else. When it is done the line says how many samplers and samples were converted. Notes:

  • An install or a conversion cut short (a cable pulled, the power lost) loses nothing: press INSTALL FIRMWARE again and the conversion goes on from where it stopped, numbering the samples as one run would.
  • A sampler that does not fit the free room stops it, and the line says how much room it needs and two ways out: delete something on the FM-1 and press INSTALL FIRMWARE again, or on the EDITOR page READ, then WRITE (the page writes the user area anew, after a backup).
  • The FM-1 holds 256 samples at most. A sampler whose samples find no free number stays in the older form: the EDITOR page lists it as OLDER FORM and says how many numbers it needs; deleting it, or other samples, frees numbers.
  • With edits not saved on the FM-1 the conversion waits: SAVE them (or REVERT), then press INSTALL FIRMWARE again.
  • CLEAN INSTALL does not convert: it erases the user area.
  • A disk of the older kind, uploaded with UPLOAD CUSTOM DISK, is converted as it loads.

Updates: a new version comes as a new install page, on PT/FM's home. Install it as above; STATUS shows the version the FM-1 runs.

CLEAN INSTALL

A fresh start. With the CLEAN INSTALL switch on, INSTALL FIRMWARE writes PT/FM and then erases everything the FM-1 holds: your work, the settings, and any damaged records. The FM-1 then starts with an empty user area and only the built-in cartridges. Upload the demo disk after it if you want the demo songs.

The FM-1 can do the same erase on its own, without a computer: SETTINGS, TOOLS, FACTORY RESET (chapter 13).

UPLOAD DEMO DISK

Needs PT/FM running on the FM-1. Afterwards the FM-1 holds exactly the demo disk: its songs, patterns, cartridges and samples take the place of yours, and what of yours is not on it is gone.

It is a fresh start with the demo disk: everything you saved goes, your settings, MIDI mappings, loops, DJ's decks and your changes to the built-in cartridges included. Only the built-in cartridges themselves stay.

  • To keep your work, back it up first on the EDITOR page: READ, then DOWNLOAD DISK (chapter 17).
  • To add the demo songs to your own work instead of replacing it, drop demo.ptfmdsk on the EDITOR page's TABLE, drag what you want onto its FM-1 panel, and WRITE.
  • If the FM-1 has edits not saved, the upload is refused: press SAVE on the FM-1 (or revert them), then upload again.
  • An upload cut short leaves what was there whole, unless the upload was replacing a nearly full FM-1's library: then part of it may be left. Either way, upload again. The FM-1 says what it found when it starts.

UPLOAD CUSTOM DISK

The same with a disk file you pick (.ptfmdsk): a backup the EDITOR page's DOWNLOAD DISK saved (chapter 17), or a disk someone gave you. Afterwards the FM-1 holds exactly that disk, everything else gone, as with the demo disk. A file that is no disk, or a disk holding nothing, is refused before anything is sent. A disk that leaves the FM-1 less than 64 KB free still goes in, and the page says what that costs its own saves: under 40 KB free, it saves nothing new until you delete something.

A disk that does not fit around what the FM-1 holds, but would fit it empty, is not written: the page offers REPLACE ALL, which erases everything the FM-1 holds and then writes the disk. Cut short, it leaves part of the disk: upload again.

UPDATE MODE

If the FM-1 does not start, or does not answer the install page:

  1. Switch the FM-1 off.
  2. Hold OCT- and switch it on. The screen says UPDATE MODE.
  3. Press INSTALL FIRMWARE on the install page.

The FM-1 also starts in UPDATE MODE by itself after two failed starts in a row, and whenever the firmware is not whole. While it installs, the screen shows INSTALLING, a bar and DON'T SWITCH OFF.

An install cut short (a cable pulled, the power lost) goes on from UPDATE MODE: switch the FM-1 on, it starts there by itself, and press INSTALL FIRMWARE again.

If something goes wrong

  • No FM-1 found: close what else uses its MIDI port (a music program, another installer, another browser tab), then try again.
  • A conversion of samplers cut short (the page said it, or the cable was pulled): press INSTALL FIRMWARE again; it goes on from there and nothing is lost.
  • Back to an older PT/FM: an older PT/FM does not read the new samples: it would count the longer ones as damaged and leave them out. So first, with the FM-1 running this PT/FM, on the EDITOR page press READ, then DOWNLOAD DISK: that copy is a must. Install the older PT/FM, then on the EDITOR page WRITE: it writes the samplers in the older form, each holding copies of the samples its instruments play, and lists in NOT KEPT what the older form cannot hold (chapter 17).
  • Back to another firmware: PT/FM keeps the FM-1's update path, so another FM-1 firmware's installer replaces it, from UPDATE MODE if need be.
