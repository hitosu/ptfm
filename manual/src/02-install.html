Installing and updating

PT/FM is installed from a web page, install.html, that comes with the firmware. It works offline: the firmware and the demo disk are inside the page. Get the latest from PT/FM's home, hitosu.github.io/ptfm, or from its repository, github.com/hitosu/ptfm (the dist folder).

Before you start

  • Open install.html in Chrome or Edge, on a computer or an Android phone. Safari and iPhones cannot talk MIDI from a web page.
  • Connect the FM-1 by USB and switch it on. Keep it connected until the page says it is done.
  • When the browser asks, allow MIDI devices, SysEx included: the whole install goes through MIDI.
Changes not yet saved on the FM-1 are lost by an install, as when it is switched off. Press SAVE on the FM-1 first.

INSTALL FIRMWARE

Writes PT/FM over whatever firmware the FM-1 runs.

  1. Open install.html and connect the FM-1.
  2. Press INSTALL FIRMWARE. The page shows its progress; the FM-1 restarts by itself.
  3. When the page says it is done, the FM-1 starts PT/FM on its STATUS screen.

Over PT/FM (an update), your songs, patterns, instruments, samples and settings stay where they are: the install writes nothing into PT/FM's own memory, the user area. Over another firmware, keep a copy of your work first: other firmwares erase that memory when they are installed. The EDITOR page saves the FM-1's whole library to a file (chapter 17).

Updates: a new version comes as a new install page, on PT/FM's home. Install it as above; STATUS shows the version the FM-1 runs.

CLEAN INSTALL

A fresh start. With the CLEAN INSTALL switch on, INSTALL FIRMWARE writes PT/FM and then erases everything the FM-1 holds: your work, the settings, and any damaged records. The FM-1 then starts with an empty user area and only the built-in cartridges. Upload the demo disk after it if you want the demo songs.

The FM-1 can do the same erase on its own, without a computer: SETTINGS, TOOLS, FACTORY RESET (chapter 13).

UPLOAD DEMO DISK

Needs PT/FM running on the FM-1. Afterwards the FM-1 holds exactly the demo disk: its songs, patterns, cartridges and samples take the place of yours, and what of yours is not on it is gone.

It is a fresh start with the demo disk: everything you saved goes, your settings, MIDI mappings, loops, DJ's decks and your changes to the built-in cartridges included. Only the built-in cartridges themselves stay.

  • To keep your work, back it up first on the EDITOR page: READ, then DOWNLOAD DISK (chapter 17).
  • To add the demo songs to your own work instead of replacing it, drop demo.ptfmdsk on the EDITOR page's TABLE, drag what you want onto its FM-1 panel, and WRITE.
  • If the FM-1 has edits not saved, the upload is refused: press SAVE on the FM-1 (or revert them), then upload again.
  • An upload cut short leaves what was there whole, unless the upload was replacing a nearly full FM-1's library: then part of it may be left. Either way, upload again. The FM-1 says what it found when it starts.

USB RESCUE

If the FM-1 does not start, or does not answer the install page:

  1. Switch the FM-1 off.
  2. Hold OCT- and switch it on. The screen says USB RESCUE.
  3. Press INSTALL FIRMWARE on the install page.

The FM-1 also starts in USB RESCUE by itself after two failed starts in a row.

An install cut short (a cable pulled, the power lost) is not resumed by itself. Press INSTALL FIRMWARE again. If the FM-1 no longer answers the page, switch it off and start it in USB RESCUE (OCT- held at power-on), then install from there.

If something goes wrong

  • No FM-1 found: close what else uses its MIDI port (a music program, another installer, another browser tab), then try again.
  • Back to another firmware: PT/FM keeps the FM-1's update path, so another FM-1 firmware's installer replaces it, from USB RESCUE if need be.
