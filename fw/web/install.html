BEFORE YOU START

  1. Open this page in Chrome or Edge, on a computer or an Android phone. Safari and iPhones have no MIDI for web pages.
  2. Connect the FM-1 by USB and switch it on. Keep it connected until the page says Done.
  3. When the browser asks, allow MIDI devices, SysEx included: everything goes through it.

The firmware and the demo disk are inside this page: it works offline and sends nothing anywhere else.

WHAT THE KEYS DO

INSTALL FIRMWARE
Writes PT/FM over whatever firmware the FM-1 runs. Over PT/FM, your songs, patterns, samples and settings stay where they are: the install writes nothing into the user area. Other firmwares erase it when they are installed: keep a copy of your work first (the editor page saves the FM-1's library as a disk). Changes not saved on the FM-1 are lost, as when it is switched off.
CLEAN INSTALL
A fresh start. With the switch on, INSTALL FIRMWARE writes PT/FM, then erases everything the FM-1 holds (your work, the settings, damaged records too), leaving an empty user area. UPLOAD DEMO DISK writes the demo disk after it, if you want it.
UPLOAD DEMO DISK
Needs PT/FM running. Afterwards the FM-1 holds exactly the demo disk: its songs, patterns and samples take the place of yours, and what of yours is not on it is gone. If the FM-1 has edits not saved, it refuses: press SAVE on it (or REVERT them), then upload again.
IF SOMETHING GOES WRONG
  • No FM-1 found: close what else uses its MIDI port (a DAW, another installer, another tab), then try again.
  • It does not start, or does not answer: switch it off, hold OCT− and switch it on. The screen says USB RESCUE (it starts so by itself after two failed starts); now press INSTALL FIRMWARE.
  • An install cut short: press INSTALL FIRMWARE again. The FM-1 waits in update mode until an install finishes.
  • An upload cut short: upload again. What was there stays whole until the new files are all in; the FM-1 says what it found when it starts.
  • Back to another firmware: PT/FM keeps the FM-1's update path, so another FM-1 firmware's installer replaces it, from USB RESCUE if need be.
